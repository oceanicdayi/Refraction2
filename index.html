Explanation｜從走時曲線建立模型

把每一支受波器的 first arrival 畫成 distance–time graph。斜率不是裝飾，而是速度的證據。

直達波t = x / V₁
折射首波t = tᵢ + x / V₂
走時圖斜率dt/dx = 1 / V

教師提示：如何形成認知衝突？

先讓學生以「地下只有一種均勻材料」預測：所有 first arrival 應形成同一條直線。接著把震源移遠或拉長 offset；當遠距離資料逐漸由折射首波控制、走時曲線出現另一個較小斜率時，再追問：「如果地下只有一種材料，為什麼會有兩種斜率？」

04

Model Revision｜用新資料挑戰你的模型

科學模型不是算完一次就結束。換一個敲擊點，看看原來的解釋還能不能成立。

試著先不改地下參數，只改變震源位置，檢驗同一模型能否解釋新的觀測。
